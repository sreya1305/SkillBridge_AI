# SkillBridge AI - Project Overview

## Introduction
**SkillBridge AI** is an intelligent, full-stack career transition and skill gap analysis platform designed to help job seekers, students, and professionals bridge the gap between their current skills and their dream target roles. 

By combining multi-format resume parsing (PDF, DOCX, Images via OCR), real-time skill matching algorithms, interactive skill gap visualizations, dynamic custom role creation, and personalized 12-week AI learning roadmaps (powered by Google Gemini 2.0 Flash), SkillBridge AI provides a complete end-to-end guidance ecosystem.

## Key Vision
Traditional career guidance platforms rely on static job descriptions and manual self-assessments that lack actionable execution steps. SkillBridge AI transforms raw career data into structured, step-by-step masterclasses, actionable capstone projects, and exportable PDF/Markdown roadmaps.

## Core Value Proposition
- **Automated Resume Skill Extraction**: Multi-modal resume parsing with OCR verification to extract candidate technical and soft skills accurately.
- **Skill Gap Matrix**: Real-time categorisation of critical, important, and nice-to-have skill gaps with quantitative match scoring.
- **AI-Powered Learning Roadmaps**: 12-week structured roadmaps with milestones, curated learning resources, and capstone project specifications.
- **Local State & Export Flexibility**: PDF & Markdown roadmap export capabilities alongside local storage persistence for browser-based offline tracking.
