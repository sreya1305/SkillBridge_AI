# Problem Statement & System Comparison

## Problem Statement
The modern hiring landscape is rapidly evolving with emergent technologies (AI/ML, Cloud Native, Full-Stack frameworks). Job seekers face three major hurdles:

1. **Unclear Skill Requirements**: Job descriptions are bloated, confusing, or lack clear hierarchy regarding which skills are critical versus optional.
2. **Inaccurate Self-Assessment**: Candidates struggle to map their existing experience against target role requirements objectively.
3. **Lack of Actionable Roadmaps**: Most career advice specifies *what* skills to learn but fails to outline *how* to acquire them, what resources to trust, or what capstone projects to build to demonstrate industry readiness.

---

# Existing System vs Proposed System

| Dimension | Existing Systems (Job Portals / Traditional Advice) | SkillBridge AI (Proposed System) |
| :--- | :--- | :--- |
| **Skill Assessment** | Manual text entry or subjective self-rating sliders | Automated Multi-format Resume Parser (PDF, DOCX, Image OCR) with dictionary verification |
| **Skill Gap Analysis** | Binary (Match / No Match) with no weighting | Weighted Gap Matrix (Critical 60%, Important 30%, Nice-to-Have 10%) with percentage scoring |
| **Target Roles** | Static pre-defined list of generic job titles | Rich default role library + Dynamic AI Custom Role Generator for specialized emerging positions |
| **Learning Guidance** | Generic course recommendations or affiliate links | Step-by-step 12-week roadmap with curated MDN/Official documentation links and actionable tasks |
| **Progress Tracking** | None or simple completion checkboxes | Real-time interactive progress tracker with milestone breakdown, study notes drawer, & PDF export |
| **AI Integration** | None or simple text chatbot | Multi-modal Gemini 2.0 Flash integration for parsing, role skill synthesis, & roadmap generation |
