## Detailed Canvas Components

### 1. Problem
- Candidates struggle to identify specific missing technical skills required for career transitions.
- Generic online courses lack alignment with specific target roles.
- No structured roadmap connects current capabilities to industry-ready capstone projects.

### 2. Customer Segments
- **Students & Graduates**: Seeking their first tech role (e.g. Full Stack Developer, Data Scientist).
- **Career Switchers**: Professionals transitioning into software engineering or AI engineering.
- **Up-skilling Developers**: Mid-level engineers aiming for specialization or promotion.

### 3. Unique Value Proposition
- Instant AI resume extraction combined with evidence verification, providing an interactive 12-week career roadmap with curated documentation links and downloadable PDF strategy reports.

### 4. Solution
- Drag-and-drop resume parsing (PDF/DOCX/Images).
- Real-time weighted skill gap matrix (Critical, Important, Nice-to-Have).
- Interactive Flowchart Node Graph + Detailed Checklist roadmap.
- Offline PDF report export.

### 5. Channels
- Organic developer community outreach (Reddit, Dev.to, ProductHunt).
- Educational partnerships with university career centers and bootcamps.
- LinkedIn career transition content marketing.

### 6. Revenue Streams
- **Freemium SaaS**: Free core gap analysis; Premium subscription for unlimited AI custom roles and advanced streaming career mentor.
- **Enterprise / Institution Plan**: B2B licenses for bootcamps and university placement cells.

### 7. Cost Structure
- Infrastructure: Server hosting, CDN, & API proxy.
- AI API Consumption: Google Gemini token costs.
- Development & Maintenance.

### 8. Key Metrics
- User acquisition & resume parsing volume.
- Roadmap generation conversion & completion rate.
- PDF download volume & user retention.

### 9. Unfair Advantage
- Multi-tier evidence verification pipeline (`skillsDictionary.js`) preventing AI hallucinations, combined with responsive client-side fallback generation ensuring 100% platform uptime.
